# HU Presentation Guidance

Use this as the current framework baseline for HU presentations:

- Establish the purpose and audience before generating slides.
- Use a clear opening, agenda, structured content, conclusion or recommendation, questions, and closing information.
- Prefer one clear message per slide, readable text, useful speaker notes, and the official HU presentation template.
- Check accessibility, including contrast, meaningful alt text, reading order, and accessible PDF export where applicable.
- Use placeholders for names and contact details until the user confirms publication-ready information.
- Preserve sources and distinguish evidence from recommendations.

Re-evaluate the official template, export requirements, and mandatory structure when the framework scales or the HU source changes.
