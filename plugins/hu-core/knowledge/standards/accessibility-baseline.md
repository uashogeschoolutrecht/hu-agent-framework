# HU Accessibility Baseline

For current framework usage, treat WCAG 2.1 Level AA as the baseline for digital output. Re-evaluate the baseline and applicable legal requirements when the framework scales.

For user-facing software and generated documents, check at least:

- Meaningful non-text content has text alternatives.
- Text contrast is at least 4.5:1 for normal text and 3:1 for large text.
- Content and functionality remain usable at 200% zoom.
- Keyboard focus order is logical and visible.
- The document or page language is programmatically identifiable.
- Interactive components expose an accessible name, role, and value.
- Colour is not the only way information is communicated.

For dashboards and interfaces, include accessibility in the design and acceptance criteria, not only in final review.
