# HU Project Decision Framework

This scoped framework guidance links project risk to decision routes and required artefacts. Re-evaluate thresholds and decision-making bodies when the framework scales to broader usage.

Use these three classes for the current framework scope:

| Class | Indicators | Decision body |
|---|---|---|
| Low | Under EUR 25,000, no or anonymised personal data, internal single-department scope | Department head |
| Medium | EUR 25,000-250,000, limited personal data, multiple departments | Directorate or project board |
| High | Over EUR 250,000, special-category personal data, external or strategic scope | Executive Board |

The source proposes intake report, project proposal, and decision document for all classes. A privacy impact assessment, security review, and data-processing agreement may be required for medium-risk work and are required for high-risk work, depending on the applicable conditions.

Agents should surface the classification, cite this document, and request human confirmation for consequential decisions. This is framework guidance, not a substitute for current HU governance decisions.
