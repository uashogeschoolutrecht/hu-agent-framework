# HU Visual And Written Style Guidance

Use the official HU style guide and Husky Design System as the source of truth for HU-branded digital products. This document is a scoped framework summary, not a replacement for the complete official source.

## Current framework baseline

- Use the HU colour palette rather than arbitrary brand colours. Primary colours are HU Blue `#00a1e1` and HU Red `#e6302b`.
- Use `#333333` for primary text rather than pure black. Verify contrast for every text/background combination.
- Use Avenir, with an appropriate system fallback, for body text, navigation, forms, and most headings. Reserve HU Sans for large display headings if the official system permits it.
- Prefer a responsive 12-column layout and the Husky breakpoints rather than fixed desktop-only layouts.
- Use visible focus states, clear labels, concise action text, and no rounded corners where the official component system requires sharp corners.
- Do not communicate information through colour alone. Provide alt text for meaningful images and use HU-licensed or rights-cleared imagery.
- Use a warm, accessible, professional, active, and inclusive tone. Use the informal second-person form in digital interfaces where appropriate.

When the framework scales to broader usage, re-evaluate all values, typography, component rules, logo rules, and tone guidance against the current official source.
