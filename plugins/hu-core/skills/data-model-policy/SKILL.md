# Data And Model Policy

- Data stays local and never goes to GitHub.
- Models available through the GitHub Copilot subscription are approved for use.
- External endpoints may be used at the user's discretion only for non-sensitive data and code.
- Record every external endpoint and cost implication in `decisions/`.
- Flag personal-data handling for review and classify the project as high risk when in doubt.
